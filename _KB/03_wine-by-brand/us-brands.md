# US Wine Brands

> Background for recognizing brands and inferring style. **Availability and price come from tools.** Styles describe the best-known wine of each brand. Producers change blends and styles over time; trust `get_product_details` for a specific bottle.

## 4. Using this table

- Customer names a brand → find the row → use **Style** to set taste filters → `get_similar_products` / `search_products`.
- Always confirm the **specific wine** for multi-tier brands (e.g., "Robert Mondavi Private Selection" vs "Robert Mondavi Winery Napa Valley").
- For "Caymus-style", describe the style ("rich, ripe, velvety"), not "same quality".
