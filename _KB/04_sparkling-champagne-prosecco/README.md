# Sparkling, Champagne and Prosecco: Folder Index

## Scope

All sparkling wine: Champagne, Prosecco, Cava, Crémant, Franciacorta, US and other traditional-method sparkling, pét-nat, sparkling rosé, sweet sparkling (Moscato d'Asti, Asti, Brachetto) and sparkling red (Lambrusco). Sparkling is a top category for **gifting, celebrations and holidays**, so peaks around New Year's Eve, Valentine's Day, Mother's Day, graduations and weddings drive demand and stock-outs.

## Category rules for the agent

1. **"Champagne" only for wine from Champagne, France.** Refer to others as sparkling wine (Prosecco, Cava, Crémant…). Don't correct customers harshly. Clarify gently when it affects the recommendation or price.
2. Peak-season stock moves fast: always `check_inventory` with the delivery date in mind.
3. Vintage and prestige Champagnes are **vintage-specific** (A-23).
4. Glass bottles under pressure: breakage claims follow [damaged-or-broken-items.md](../12_returns-refunds-damages/damaged-or-broken-items.md); safety handling is in the occasions file.
