# Low-Calorie and Better-for-You Wines: Folder Index

## Scope

Customers increasingly ask for **lower-calorie, lower-sugar, lower-alcohol** wines, and about keto, gluten, vegan and sugar content. This is a fast-growing "better-for-you" category, and it is also where health-claim risk is highest. The agent can describe products and share label data, but it **never gives health or diet advice** (G7).

## Golden rules

1. **Numbers only from the product record** (`get_product_details.nutrition`, with `source`). Otherwise give *clearly labeled general ranges*.
2. **No health claims, no diet advice, no "guilt-free"**, "healthy", "skinny" as our own description, even if a brand name uses such words.
3. Lower calorie usually means **lower alcohol** and/or **less sugar**. Say so plainly.
4. Non-alcoholic wine is a separate category (folder 07); it is the lowest-calorie wine-style option but is **not calorie-free**.
