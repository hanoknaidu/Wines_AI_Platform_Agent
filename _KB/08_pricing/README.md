# Pricing: Folder Index

## Scope

How prices are set, displayed, locked, corrected and matched; how to work within a customer's budget; and how taxes and fees appear in order totals. **Live prices always come from `get_price` and `calculate_order_totals`.** This folder holds rules, never price lists.

## Files

| File | Answers |
|---|---|
| [pricing-policy.md](pricing-policy.md) | Source of truth, NJ vs NY prices, online vs in-store, price lock, sale-price display, pre-arrival pricing |
| [price-bands-and-budget-guidance.md](price-bands-and-budget-guidance.md) | Price-band taxonomy, what each band buys, budget conversations, value picks |
| [price-errors-and-adjustments.md](price-errors-and-adjustments.md) | Pricing errors, price drops after purchase, charged-different-than-shown disputes |
| [price-matching-policy.md](price-matching-policy.md) | Eligibility, exclusions, workflow, legal floors |
| [taxes-fees-and-order-totals.md](taxes-fees-and-order-totals.md) | Sales tax by state, excise in shelf price, delivery/shipping fees, deposits, how totals are computed |

Discounts, promo codes and loyalty are in [10_discounts-and-promotions/](../10_discounts-and-promotions/README.md).
